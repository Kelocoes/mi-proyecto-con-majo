# Actividad evaluativa

Comandos de interés:

- Agrega `--no-verify` para omitir las verificaciones de husky:

```bash
git commit -m "mensaje" --no-verify
```

```bash
git push --no-verify
```

- Están los comandos de prettier y eslint en los scripts de `package.json`:

```bash
# Arreglar problemas de linting
npm run lint:fix
# Formatear código
npm run format
```
